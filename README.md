# React App

This project contains a React application with ESLint support for React hooks.

## React Compiler

The React Compiler is not enabled in this template because of its impact on development and build performance. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled and choosing a bundler or build tool that fits your workflow.
